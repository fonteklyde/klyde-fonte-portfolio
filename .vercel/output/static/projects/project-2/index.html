DevPath

A web-based career guidance system built with ReactJS, Python, and Firebase that analyzes students’ academic records, technical assessments, and profile surveys to predict personalized IT career paths.

Technologies Used

React.jsPythonFirebase
Live Demo ↗

Project Overview

Selecting the right specialization in Information Technology can be overwhelming for students due to the vast array of career tracks (Web Development, Data Science, Cybersecurity, Systems Administration, DevOps).

DevPath is an intelligent career guidance platform designed to analyze a student’s academic background, skill proficiencies, and personal interests to recommend tailored IT career roadmaps and growth plans.

Key Features

  • 🎯 Personalized Career Path Prediction: Analyzes skill test scores and academic records using Python data processing pipelines to generate ranked career recommendations.
  • 📝 Interactive Skill Assessments: Interactive diagnostic quizzes designed to evaluate practical knowledge across programming logic, networking, database management, and UI design.
  • 🗺️ Interactive Learning Roadmaps: Step-by-step visual skill trees detailing essential technologies, recommended courses, and industry certifications required for each path.
  • ⚡ Real-Time Student Dashboard: Built with React.js and Firebase Realtime Database for instant progress tracking and profile synchronization.

Architecture & Implementation

  • Frontend: React.js SPA deployed on Vercel, providing an interactive, responsive user interface with smooth step-by-step assessment forms.
  • Backend Analytics Engine: Python service responsible for running recommendation scoring models and processing assessment metrics.
  • Database & Authentication: Firebase Authentication and Firestore DB for scalable user account storage and real-time updates.

Results & Impact

DevPath successfully helped hundreds of IT students gain clarity on their career trajectories, providing structured learning roadmaps that bridge academic curriculums with current tech industry requirements.
